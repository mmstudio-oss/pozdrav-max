ПОЗДРАВЬ — ЭТАП 2

Что умеет эта версия:
- ввод имени;
- выбор повода;
- выбор стиля текста;
- 5 визуальных шаблонов;
- генерация красивой открытки на HTML Canvas;
- размер PNG: 1080x1350;
- сохранение PNG на устройство;
- попытка открыть системное меню "Поделиться" с PNG.

СЕРВЕР НЕ НУЖЕН.
Всё работает прямо на GitHub Pages.

КАК ОБНОВИТЬ СТАРЫЙ ПРОЕКТ:
1. Откройте репозиторий pozdrav-max на GitHub.
2. Замените старые index.html, style.css и app.js файлами из этого архива.
3. Сделайте Commit changes.
4. GitHub Pages автоматически опубликует новую версию.
5. Откройте адрес сайта и обновите страницу.

ВАЖНО:
Прямая отправка PNG в чат MAX через кнопку внутри мини-приложения
будет сделана на этапе 3. Для неё нужен сервер + MAX Bot API,
чтобы загрузить/отправить картинку и получить идентификатор сообщения.

На этом этапе можно:
Создать открытку -> Скачать PNG -> отправить её вручную
или использовать системную кнопку "Поделиться PNG", если браузер её поддерживает.
